Viewpoint internals list

Open Markdown

Use viewpoint.api when you can. If the API does not have what you need, you can use or hook the members on this page.

  • Every member on this page has a level: Amber or Red. The level goes on the label of your addon.
  • An addon that uses or hooks a member on this page is never Normal.
  • Internal members can change in each Viewpoint release. Your addon can stop working after an update. Test it after each release. Internals changes lists what each release changed.
  • Viewpoint does not load a jar that uses or hooks a member that is not on this page.
  • A new member from this page in an update needs the consent of the player again. See Updates & changelogs.

The list

Section titled “The list”

Viewpoint makes this list for each release, from the list that the maintainers review. The release build writes the tables below. Do not edit them by hand.

Each class has a block. The heading of the block is the full name of the class. Under it, the block says whether the class is public, and its level. A row in the block is one member. The columns are:

ColumnMeaning
MemberA field, or a method with its descriptor.
Use or hookWhat you can do with the member. Use means that you call the method or read the field. It is possible only when the class and the member are public. Hook means that you put a hook on a method. It is possible for any access. Reflect means that you look up the member by name with reflection. It is possible for any access.
ThreadThe thread on which the member runs: main, render, any or worker. It decides the kind of hook that you can use. See Hooking Viewpoint.
LevelAmber or Red. Reflection into any member is always Red.
SinceThe Viewpoint release in which the member came on the list.
ReplacementThe viewpoint.api type that does the same, if there is one. A deprecated member names its replacement here.

A member can be hook only. You can hook it, but you cannot call it.

A field on this page is for reading. You cannot write to it. Use viewpoint.api to change the state of Viewpoint.
