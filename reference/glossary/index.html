Glossary

Open Markdown
TermMeaning
AddonA package with Java code, described by addon.properties. It can also contain assets, shader snippets and Lua.
Resource PackA package with assets only (models, tiles, sounds, data), described by pack.properties. It has no Java and no shader code.
ShaderpackA package with GLSL files and their options, described by pack.properties. It has no Java. It changes how Viewpoint draws the world.
PackageAn addon, a resource pack or a Shaderpack.
BaseThe pack that a Shaderpack builds on, named by base=.
Encoded idAn id with . and - written as _. It is used in settings keys and in GLSL names.
DescriptorThe file that describes a package: addon.properties or pack.properties.
HookA declaration in your jar that connects a handler to a game method. Viewpoint installs it.
HandlerYour public static method that Viewpoint runs before or after the hooked game method.
KindWhat a handler can do: OBSERVE, ARGS, RETURN or SKIP.
PermissionA service that an addon asks for in permissions: hooks, files, downloads, lua, camera, combat, models, shaders or draw.
LabelThe result of Viewpoint’s automatic check, on the card: Normal, Amber or Red.
Lua lineThe last line of each label. It tells if the package has Lua. Viewpoint does not check Lua.
Shader lineA line of a card that says that the package has shader code. Viewpoint checks its size and form, not what it computes.
ExportA Java function of an addon that the Lua of any mod can call.
ServiceAn object that an addon publishes under an id, so that other addons can use it.
Camera layerA small change that an addon adds to the camera. Many layers can be active together.
ClaimA right that only one addon at a time can hold, for example the camera, the cursor or the reticle. The addon nearer the top of the Active column wins.
ProviderAn object that an addon gives to Viewpoint to choose the model of a world object or of a character.
Shader valueA number that an addon sets, and that shader code reads as uAddon_<encoded id>_<name>.
SnippetA small piece of GLSL that an addon adds at a named point of a shader.
Draw callbackA function of an addon that Viewpoint calls at a named point of a frame, so that the addon can draw.
Internals listThe members of Viewpoint outside viewpoint.api that an addon can use or hook.
ConsentThe player’s acceptance of one version of one package. An update that asks for more needs consent again.
CardThe row that shows one package in the settings window.
Active columnThe list of the packages that are on. The package nearer the top wins.
Safe pointA time when Viewpoint can install and remove hooks: the main menu, a loading screen, or a paused single-player game.
RegistrationAn object that the API gives you for a listener or a callback. Viewpoint closes it when the addon goes off.
LegacyA flag for an older Viewpoint model pack. It is a resource pack.
UnmanagedA flag for a mod that loads its Java through ZombieBuddy (javaJarFile). Viewpoint does not control it.
GoneA member of Viewpoint that a release removed. An addon that uses it shows Needs an update.
SuspendedThe state of an addon that Viewpoint stopped for the session, after an error or on a server that does not list it.
PoolA part of memory with a maximum size, for one kind of asset.
